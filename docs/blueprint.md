# **App Name**: GreenDay Planner

## Core Features:

- Task Creation: Add tasks with title, details, and deadlines to a specific day.
- Task Completion: Mark tasks as complete to visually track progress.
- Daily Overview: Provide a daily schedule view that displays all tasks and events.
- Entry Editing: Edit existing tasks, change their details, or reschedule them.

## Style Guidelines:

- Primary color: A calming light green (#A7D9A8) to promote a sense of tranquility and focus. Chosen for its alignment with nature and clarity.
- Background color: Off-white (#F5F5F5), almost imperceptibly green, to maintain a clean and calm aesthetic, complementing the light green.
- Accent color: Soft Yellow (#D4AC0D) for important CTAs.
- Body and headline font: 'PT Sans', sans-serif.
- Simple, clean icons for task categories and navigation.
- A minimalist layout with clear separation of tasks and events for easy viewing.
- Subtle animations to indicate task completion.
